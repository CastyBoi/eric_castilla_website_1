Side Project · Case Study

Apache NiFi Data Pipeline & Realtime Weather Tracker

A self-directed dive into ETL tooling: scraping, scheduling, and piping data into SQL Server and Tableau, end to end.

What I set out to build

I wanted to get hands-on with a scalable, industry-standard ETL tool. I picked Apache NiFi — open source, free to run locally, and built by a major player in the data engineering space. Concisely, the goal was:

  • Automatically execute a web-scraping program that outputs an Excel file, then move the file to another location.
  • Execute a second program that hits an open-source weather API and pulls current weather.
  • Ingest both into the ETL tool for formatting.
  • Insert the result into a SQL Server table, connected live to a Tableau dashboard.

Pipeline outline

Building this pipeline meant learning several of NiFi's processors and getting familiar with their syntax and configuration. There was a real learning curve, but once the ODBC connections were set up and my Python programs were executing properly on schedule, it came together.

Realtime weather tracking dashboard

Built in Tableau Desktop, connected directly to the SQL Server table this pipeline feeds. (Not embedded here since it runs off the desktop version and I wanted to keep the display live.) End product: an interactive dashboard with historical, current, and forecasted weather data alongside several other metrics.
